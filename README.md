# Android Multi Game Manager

- 기본 화면을 초간단 모드로 재설계
- 사용 순서: 인스턴스 선택 → Google 로그인 → 게임 검색/설치 → 실행
- CPU/RAM/FPS/해상도/패키지/APK/그룹/동기입력/로그/백업은 고급 설정으로 이동

- 패키지 placeholder com.example.game 기본 노출 제거
- v1.8.2의 ADB 복구, Google 계정 fallback, updater/AVD 복원 기능 유지
